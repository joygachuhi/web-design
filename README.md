Web-Design
  My Web Design Project

  1. Project Description
Kenya's Number Ome News Blog is a simple, responsive news website built using HTML and CSS.
It displays news articles across various categories such as Technology, Sports, Politics, Health, Business, Entertainment and more.
The project is designed to practice web design fundamentals, layout structuring, and content presentation. 

  2. Project Features
Simple and clean design 
News logo with an image 
Image-supported articles
Responsive layout for news articles
Header Navigation Menu
Footer with copyright information

  3. Languages Used
HTML5 - Page Structure
CSS - Styling and layout
 
  4. Project Structure
The project consists of the following files and folders:
  index.html - The main HTML file containing the structure of the news blog.
  README.md - This file, providing project details and instructions.

  5. Preview
The website displays:
  A header with logo and navigation bar.
  A grid of news articles with images and descriptions.
  A footer with copyright details.
